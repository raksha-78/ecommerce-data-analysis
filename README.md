# Olist E-Commerce Data Analytics Project

## 📌 Project Overview

This project analyzes the real-world **Olist Brazilian E-Commerce Public Dataset** to understand customer behavior, sales performance, product performance, order trends, payments, reviews, and delivery performance.

The project uses **Python, Pandas, PostgreSQL, SQL, and Power BI** to perform data cleaning, data-quality analysis, database analysis, and business visualization.

## 🎯 Project Objectives

- Understand and profile real-world e-commerce data.
- Perform data cleaning and data-quality checks.
- Identify missing values and duplicate records.
- Validate relationships between different datasets.
- Store structured data in PostgreSQL.
- Perform business analysis using SQL.
- Create interactive Power BI dashboards.
- Generate meaningful business insights from the data.

## 🗂️ Dataset

The project uses the **Olist Brazilian E-Commerce Public Dataset**.

The dataset contains 9 CSV files:

1. `olist_customers_dataset.csv` – Customer information.
2. `olist_geolocation_dataset.csv` – Geographical information.
3. `olist_order_items_dataset.csv` – Order items, products, sellers, prices, and freight.
4. `olist_order_payments_dataset.csv` – Payment information.
5. `olist_order_reviews_dataset.csv` – Customer reviews and ratings.
6. `olist_orders_dataset.csv` – Order status and order timestamps.
7. `olist_products_dataset.csv` – Product information and attributes.
8. `olist_sellers_dataset.csv` – Seller information.
9. `product_category_name_translation.csv` – Product category translation.

> Raw CSV files are excluded from GitHub using `.gitignore`.
